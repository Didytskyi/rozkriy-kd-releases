# Розкрій КД — автономна версія

Оптимальний лінійний розкрій пиломатеріалів для розділу КД: схеми розкрою, специфікація «Купити / З наявного», звіт для друку в PDF і етикетки для деталей.

**Вебверсія:** https://rozkriy-kd.vercel.app — її можна встановити як програму прямо з браузера (Chrome, Edge) і працювати без інтернету.

## Windows — один файл

Завантажте `Rozkriy-KD-<версія>.exe` з розділу [Releases](../../releases/latest).

- Без встановлення: запустіть файл — програма відкриється окремим вікном.
- Потрібен Microsoft Edge або Google Chrome.
- Проєкти зберігаються на цьому комп'ютері. Щоб перенести проєкт із браузера, збережіть його там кнопкою «Зберегти файл» і відкрийте в програмі через «Відкрити файл».

## macOS · Linux

Окремих файлів поки немає — скористайтесь вебверсією і встановіть її як програму з браузера.
